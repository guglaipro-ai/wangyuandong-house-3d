# 王源東住宅 3D 概念模型

依確認版請照圖製作的住宅展示模型。開啟 [住宅3D檢視器.html](./output/住宅3D檢視器.html) 可用滑鼠或手機觸控旋轉、縮放、俯視，並隱藏樓層／屋頂查看室內。

這是概念／展示模型，不是施工圖、竣工測量或結構安全認證。模型以 PDF 平面、立面、剖面與門窗表重建；未完整標註的框料、格柵、收邊及配色依已確認的展示假設處理。

完整檔案與限制說明在 [`output/使用說明.md`](./output/使用說明.md)、[`output/模型假設與來源.md`](./output/模型假設與來源.md) 與 [`output/模型檢查清單.md`](./output/模型檢查清單.md)。
